# 🦁 Roe’s Zoo — Interactive Zoo Website Project

An educational and engaging full-stack zoo website system built for the Digital Systems Project.  
Users can explore animals, play quiz games, register for an account, favorite animals, and book discounted tickets.

---

## 📌 Features

- 🐾 **Interactive Zoo Map**: Click animal icons to view info or jump to their profiles.
- 🧑‍💻 **User System**: Register, login, update profile (username, password, avatar).
- 🌟 **Favorites**: Mark animals and view them highlighted on the map.
- 🎮 **Animal Quiz Game**: 5-question daily game; earn a **one-time ticket discount** by scoring full marks.
- 🎫 **Ticket Booking**: Buy tickets with real-time pricing and discounts.
- 💬 **Anonymous Feedback**: Users can submit suggestions without logging in.
- 🔍 **Search Bar**: Type animal names to quickly find them.
